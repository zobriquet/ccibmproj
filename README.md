# britishMuseumPrototype

## Getting Started

TO get this working offline on mac these are the pre requisites
have node.js installed
enter the file in terminal with the command cd "blah/blah/britishMuseumPrototype"
then run npx-install to get the missing node files

## Running Locally
if all the above has been done it should be able to run locally as p5js library is locally installed
step 1 open a terminal window and enter the file with the command cd "blah/blah/britishMuseumPrototype"
step 2 once in the file run the command node server.js to listen for the potentiometers the port name needs to match its currently my mac port names
step 3 in a new terminal window repeat step 1
step 4 once in the file run the command npx http-server
step 5 copy the link given and that will be the p5js sketch
